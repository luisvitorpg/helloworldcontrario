# Programa "Hello World" ao contrário
### Sim, eu consegui fazer a proeza de fazer um programa "Olá Mundo" ao contrário.
> *Mas Luís Vitor, como assim ao contrário?*
Simples, na linguagem C, um programa "Olá mundo" normal seria assim:
```
#include <stdio.h>

int main(int argc, char *argv[]) {
  printf("Hello World!\n"); // Faz parte do contexto de ser ao contrário
  return 0;
}
```
Mas se fosse ao contrário, seria assim:
```
HelloWorld(printf);
```
Consegui essa proeza através de alguns headers, como pode ser visto no main.c e no Makefile.
